What Claude Code was missing.

Claudy drives the real claude binary, so your plugins, memory and settings work as they do in the terminal. Everything else here is what developers kept switching windows for.

Chat with Claude CodeStreaming, with every tool call visible.

  • Readable outputMarkdown, syntax highlighting and collapsible cards for Bash, Read, Edit, Grep, todos and agents.
  • Plan, Ask, Edits, AutoSwitch with ⇧Tab mid-session. Plans get an approval card before anything is touched.
  • Permission promptsAllow once, always allow for this chat, or deny with a note to Claude.
  • Session historyResume and search any conversation from ~/.claude/projects.

Review and undoEvery turn is snapshotted.

  • Last-turn changesOpen “N files changed” to see unified or split diffs, then revert one file or the whole turn.
  • Works anywhereSnapshots live in a shadow git repo outside your project. They catch Bash edits and work in folders without git.
  • File historySee every turn and commit that touched a file.

Built-in browserPreview your dev server beside the chat.

  • Localhost links open hereToggle with ⌘⇧B. The page stays loaded while the panel is hidden.
  • Point at an elementComment on it with a cropped screenshot attached, or send the whole viewport.
  • Claude can drive itNavigate, click, type, screenshot and read console logs. Running JavaScript asks you first.

Project toolsOne window per project.

  • GitBranches, AI-written commit messages, a history graph, rebases, cherry-picks and a conflict editor.
  • DatabaseBrowse and edit MySQL or MariaDB from a Laravel-style .env, with a SQL console.
  • RunStart package.json scripts or flutter run on any device, with a live log.
  • Files, memory, pluginsAn IDE-style file tree, CLAUDE.md and permission editing, and a plugin browser.

Terminal and serversShells and SSH without leaving the app.

  • TerminalTabbed login shells, as their own view or as a panel inside each chat.
  • ServersSSH and SFTP from a password-encrypted vault, with setup recipes for Nginx, PHP, MariaDB, PM2 and Docker.

CoworkClaude on documents, not just code.

  • Tasks on filesAttach folders or get a scratch folder. Switch to Cowork with ⌘⇧K.
  • See the outputA side panel shows progress, produced files, connectors and document skills.

Install in a minute.

Releases are signed with a Developer ID and notarized by Apple, so macOS opens them without warnings.

  1. Download the DMG

    Get Claudy-<version>-arm64.dmg from the button above or the latest release.

  2. Drag Claudy into Applications

    Open the DMG and drop the app into your Applications folder.

  3. Open a project folder

    Claudy finds claude on your shell PATH, in ~/.local/bin or in Homebrew. If it's missing, Claudy offers to install it.

Claudy updates itself

Every hour it checks for a new release, downloads the zip, verifies its SHA-512 checksum and swaps the app in place on your next restart.

To check by hand, open Settings › About. It also shows your version and build.

So does Claude Code

Claudy runs claude update on launch and every 6 hours. You can turn this off in Settings.

The ↻ button in a chat header restarts that chat on the new CLI version without losing its context.

Troubleshooting

Most problems come down to where the CLI lives or a macOS permission.

Still stuck? Report an issue with your Claudy version from Settings › About and your macOS version.

Claudy says it can't find claude

Set the CLI path in Settings, or install Claude Code with curl -fsSL https://claude.ai/install.sh | bash and reopen Claudy.

macOS won't open the app

Downloads from this site are notarized, so this shouldn't happen. If it does, open System Settings › Privacy & Security and choose Open Anyway next to Claudy.

Notifications don't appear

Allow notifications for Claudy in System Settings › Notifications. Claudy plays a sound, posts a notification and badges the Dock when a chat needs you.

I'm on an Intel Mac

Only Apple Silicon builds are published right now.
